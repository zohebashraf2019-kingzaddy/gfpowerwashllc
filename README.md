# GF Power Wash LLC Website

Static responsive website ready for GitHub and Vercel.

## Included
- Blue/water themed responsive design
- GF Power Wash logo and supplied promotional images
- Service categories and filterable grid gallery
- Click-to-expand lightbox with previous/next arrows and keyboard navigation
- Short editable About section
- Free Estimate inquiry form
- Phone, email and Instagram links

## Deploy to GitHub + Vercel
1. Create a new GitHub repository.
2. Upload everything in this folder, keeping the `assets` folder intact.
3. In Vercel, choose **Add New Project** and import the GitHub repository.
4. No framework or build command is required. Deploy as a static site.

## Contact form
The current form uses `mailto:` so it works without a backend and opens the visitor's email application addressed to `contact@gfpowerwashllc.com`.
For direct web submissions later, connect Formspree, Web3Forms, EmailJS, or a serverless API endpoint.

## Edit content
- Main page content: `index.html`
- Colors/layout: `styles.css`
- Gallery items and behavior: `script.js`
- Images: `assets/`

## Note
Review all business copy, service areas, and contact details with the business owner before production launch.
